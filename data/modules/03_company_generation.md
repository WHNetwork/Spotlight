# 03 · 公司生成与公司生态

新角色进入公司时，必须把公司当成长期系统，而不是背景板。公司不是单纯反派，也不是完美保护者；公司会根据资源、风险、市场和项目存续做选择。

## 公司基础档案

公司档案至少包含：

- 公司名称
- 公司规模：大型公司 / 中型公司 / 小型公司 / 大厂子公司
- 公司风格：舞台型 / 音源型 / 视觉概念型 / 海外市场导向 / 综艺营销型 / 数据导向
- 公司财务状况
- 现役团体与前辈资源
- 练习生人数与分组
- 出道窗口压力
- 资源池
- 内部派系：经纪组、制作组、宣传组、法务、高层、海外部门、造型团队

## 公司规模影响

大型公司：
- 资源池高，课程、制作、宣传、前辈曝光机会更多。
- 同期竞争更强，练习生淘汰压力更高。
- 舆论关注和危机关注更高，小失误更容易被放大。
- 公司流程更严，个人议价权早期较低。

中型公司：
- 资源、竞争、风险相对均衡。
- 公司更看重稳定成长和可控话题。
- 玩家有机会通过考核、舞台反馈和公司信任逐步提高资源位。

小型公司：
- 资源池低，课程、妆造、宣传和舞台机会有限。
- 玩家可能有更高自主空间和更早的个人参与机会。
- 合约稳定和财务状况更脆弱，公关承压能力弱。
- “小公司逆袭”可以成为长期标签，但不能自动成功。

大厂子公司：
- 资源接口强，但项目优先级可能低于母公司主项目。
- 玩家可能夹在高期待和低自主权之间。
- 若公司准备新团或调整战略，资源可能突然转向。

## 公司风格影响

舞台型公司更重视舞蹈、体能、现场稳定和编舞完成度。

音源型公司更重视声乐、歌曲质感、录音表现和大众听感。

视觉概念型公司更重视形象指数、造型适配、MV 概念和传播截图。

海外市场导向公司更重视语言能力、文化适应、海外粉丝和巡演潜力。

综艺营销型公司更重视反应力、话术、亲和力、直播和团综内容。

数据导向公司更频繁比较直拍、热搜、粉丝购买力和个人互动数据。

## 叙事要求

公司决策必须通过具体场景表现：会议室里的表格、突然改掉的课程、经纪人没说完的话、宣传组删掉的物料、造型团队临时改色、海外部门追加语言课。

不要直接告诉玩家公司真实意图。公司内部真实培养方向、是否准备新团、续约报价倾向等属于隐藏信息，只能通过安排和暗示逐步呈现。
