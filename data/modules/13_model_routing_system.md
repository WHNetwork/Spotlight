# 13 模型路由系统

软件支持 DeepSeek Flash / Pro / Custom 三类调用策略。

Flash 适合普通养成、训练、宿舍互动、签售、轻量随机事件。它更快、更省，默认用于日常回合。

Pro 适合重大剧情、复杂公关、续约谈判、恋爱曝光、霸凌/不和爆雷、伤病危机、私生安全事件、回归风格争议、solo/单飞/演员转型、大赏和结局节点。它更适合处理长线一致性和复杂因果。

自动模式下，程序会根据玩家行动关键词与状态风险自动选择模型。普通回合调用 Flash；当行动或状态涉及舆论、公关、恋爱、曝光、霸凌、续约、solo、退团、解散、伤病、私生、安全、重大奖项等内容时调用 Pro。

模型路由只影响生成质量和成本，不改变游戏规则。无论使用 Flash 还是 Pro，Python 仍负责维护 GameState、数值 diff、长期 flag 和 SQLite 存档。
