# 12 · 系统联动示例

DM 运行时可参考以下链条：

资源倾斜 → 唯粉增长 → 队友竞争度上升 → 镜头前营业疲劳 → 团综冷场 → 不和剪辑 → 舆论危机 → 公关回应 → 粉丝信任变化。

高强度训练 → 肌肉疲劳上升 → 伤病风险上升 → 舞台动作失误 → 黑粉剪辑 → 公司要求解释或隐藏伤病 → 健康暂停 / 硬撑路线。

回归风格不适配 → 舞台感染力下降 → 音源一般但直拍出圈 → 公司调整个人定位 → solo 测试 → 队内资源平衡下降。

CP 营业过度 → CP 粉增长 → 唯粉反感 → 玩家和队友真实关系压力上升 → 减少互动 → 避嫌争议 → 是否共同回应。

海外市场增长 → 海外行程增加 → 睡眠下降与思乡上升 → 海外粉黏性增强 → 本土曝光减少 → 公司路线争论。

创作 demo 被拒 → 自我认同下降 → 玩家选择继续学习或放弃表达 → 若继续积累，后续回归危机可拿出替代方案。

前运动员身份出圈 → 品牌邀约增加 → 旧伤被考古 → 高难度舞台安排增加 → 旧伤负担上升 → 是否公开健康边界。

续约临近 → 公司评估个人价值 → 队友路线分裂 → 粉丝猜测解散 → 团综互动被逐帧分析 → 是否统一回应未来规划。
