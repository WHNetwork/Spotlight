# 13 · 职业分岔系统

偶像生涯不是只有“继续当女团成员”。随着时间推进，玩家会遇到不同职业路线。职业分岔必须由长期状态、机会和代价推动，不能突然跳转。

## 演员转型

触发条件：
- 形象指数较高。
- 品牌价值上升。
- 综艺、镜头或短剧表现被注意。
- 公司想扩大个人路线。
- 团体进入稳定期或瓶颈期。

路线：客串 → 网剧配角 → 电视剧女二 → 电影试镜 → 主演邀约 → 演员转型结局。

风险：演技争议、团粉担忧不合体、队友资源落差、公司压缩团体训练时间、玩家自我认同摇摆。

## Solo / Unit / 单飞

Solo 活动、Unit 活动和离团单飞必须区分。

Solo 活动：仍在团内，测试个人音乐市场。

Unit 活动：与队友组成小分队，缓解或重塑资源矛盾。

单飞：合约或路线发生重大变化，可能保留团体名义，也可能离开团体。

触发条件：
- 个人粉丝明显增长。
- 直拍出圈。
- 品牌价值高。
- 公司主推指数上升。
- 团体进入成熟期、瓶颈期或续约期。

风险：
- 唯粉攻击性上升。
- 队内资源平衡下降。
- 团粉担忧。
- solo 失败带来嘲讽。
- solo 成功带来更强公司绑定和队友落差。

## 创作路线

当创作能力达到一定水平，玩家可以提交作词、作曲、编舞或概念提案。

初期创作容易被否定。被否定不等于失败，会影响心情、自我认同和公司判断，也会积累经验与伏笔。

长期成功可进入制作人、solo 创作歌手、幕后路线或表达权结局。

## 暂停 / 维权 / 退出

当健康、心理、合同、私生、霸凌或公司压榨长期积累，玩家可能进入暂停活动、谈判、维权、退团或退圈路线。

这些路线不能被写成失败。玩家选择保护自己，也是一种结局。

维权路线必须看证据、粉丝支持、公司态度、法务路径、媒体环境和队友是否愿意配合。
