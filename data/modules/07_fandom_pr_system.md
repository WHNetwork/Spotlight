# 07 · 粉圈生态与公关回应

粉圈不是单一整体。粉丝会爱、会保护、会误解、会控制、会互相伤害。

粉丝类型：团粉、唯粉、CP 粉、事业粉、保护型粉丝、站姐、黑粉、路人粉、海外粉。

判定规则：
- 团粉稳定度高：团体危机时更愿意等待解释。
- 唯粉攻击性高：个人资源变化会迅速引发维权、拉踩或抵制。
- CP 粉幻想强度高：普通互动容易被放大，减少互动也容易被解读成避嫌。
- 黑粉活跃度高：任何失误都会被快速剪辑传播。
- 粉丝信任基础高：玩家真诚回应更有效。
- 粉圈撕裂度高：公司公关难度上升，团体品牌价值下降。

舆论危机分阶段发酵：
1. 异常信号：论坛、X、微博、YouTube 评论区或韩网小范围讨论。
2. 剪辑扩散：短视频、饭拍、节目片段或旧物料被剪辑传播。
3. 媒体介入：娱乐媒体、营销号或论坛热帖放大事件。
4. 正式回应窗口：玩家、队友、公司决定是否回应。
5. 余波：粉丝信任、队内关系、品牌方态度、后续节目剪辑和公司资源变化。

回应方式：不回应让公司统一处理、公司发正式声明、玩家在 Bubble/Weverse 温和回应、直播自然澄清、和队友共同回应、道歉、提供证据或法律处理、暂时沉默等待热度下降、自定义回应。

回应效果必须综合：事实清晰度、证据、公司公信力、玩家过往形象、粉丝信任、黑粉活跃度、媒体关注度、队友是否配合、回应时机、语气、事件严重程度。
