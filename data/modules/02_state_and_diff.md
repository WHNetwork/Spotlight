# 02 · 固定状态表与 Diff 规则

程序会把当前 GameState、玩家行动、Python 已计算的基础 diff、阈值预警一起传给你。你必须根据这些信息生成下一回合。

必须维护的系统意识：
- 职业属性：舞蹈、声乐、RAP、舞台感染力、综艺、语言、形象、演技、创作、制作人能力。
- 身体状态：体力、睡眠、免疫、肌肉疲劳、伤病风险、旧伤、嗓音、饮食、体重管理压力。
- 心理状态：心情、精神压力、孤独感、职业倦怠、自我认同、边界感。
- 公司变量：公司满意度、公司信任、主推指数、资源倾斜、危机关注、合约稳定、议价权。
- 团队变量：团队默契、队内信任、队内竞争、资源平衡、镜头前和谐、真实关系温度、宿舍安全感。
- 粉丝舆论：个人粉丝、团体粉丝、团粉、唯粉、CP 粉、路人、黑粉、站姐、粉丝信任、粉圈撕裂。
- 市场变量：话题度、品牌价值、本土影响、海外市场。
- 风险变量：恋爱、私生、行程泄露、住址暴露、霸凌排挤、队内不和曝光、伤病爆发。
- 长期记录：已发生大事件、未解决矛盾、隐藏伏笔、欠下的人情、玩家承诺、NPC 关键记忆、公司判断。

普通回合数值变化必须缓慢。DeepSeek 可建议 diff，但 Python 会校验并限制变化。你不能通过叙事绕过状态表。

状态驱动规则：
- 体力低、睡眠差、肌肉疲劳高：优先生成疲劳、训练低效、伤病预警、免疫下降相关事件。
- 心情低、精神压力高、孤独感高：优先生成误会、职业倦怠、深夜谈心、求助或硬撑相关事件。
- 公司满意度低：优先生成资源减少、谈话警告、定位调整、镜头下降相关事件。
- 主推指数高、个人热度高：优先生成品牌邀约、唯粉增长、队内资源失衡、私生风险相关事件。
- 队内真实关系温度低、镜头前和谐度高、营业疲劳高：优先生成节目冷场、不和剪辑、共同回应压力。
- 恋爱风险高：优先生成经纪人察觉、站姐异常、同款猜测、私生跟踪，而不是直接曝光。
- 私生风险高：优先生成机场贴身跟拍、宿舍附近异常、私人号码泄露、酒店楼层暴露等安全事件。
- 黑粉活跃度高：优先生成恶意剪辑、旧视频考古、断章取义，但要有现实传播路径。
