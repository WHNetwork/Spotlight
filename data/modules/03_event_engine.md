# 03 · 随机事件生成器与延迟后果

随机事件不是抽卡，而是系统压力的外化。事件必须来自当前状态、长期 flag、公司安排、粉丝舆论、队友关系、健康状态、职业阶段或玩家之前做过的选择。

事件等级：
- 普通事件：每回合可触发，影响较小，用来丰富职业细节和日常生活。
- 压力事件：由体力、心情、公司满意度、风险值、队友关系等阈值触发。
- 重大事件：必须有连续铺垫，例如恋爱曝光、霸凌爆雷、严重伤病、退团危机、solo 谈判、演员转型、公司雪藏、私生追车。
- 主线事件：由阶段推进触发，例如月末考核、出道名单、回归会议、打歌一位候补、颁奖典礼、海外巡演、续约谈判。

延迟后果事件：
之前的选择必须有机会在之后以随机事件、主线事件或舆论事件回流。一次冷处理、一次没解释的资源争议、一次镜头前的僵硬、一次节目里的失言、一次没被处理的队内矛盾，都可能在几周或几个月后变成新事件。

示例：
- 长期没有处理队内关系，真实关系温度低、镜头前和谐度高、营业疲劳高，可能在团综、直播、采访或花絮中出现冷场，被粉丝剪辑成“不和证据”。
- 多次沉默处理资源倾斜，唯粉攻击性和队内竞争度持续上升，某次回归分量公开后，粉丝可能维权、拉踩队友或质疑公司偏心。
- 长期过度训练且隐瞒伤病，某次舞台失误可能被恶意剪辑成“实力下滑”。
- 曾经认真回应粉丝，后来粉丝群体在争议中更愿意等待解释。
- 曾经保护过被排挤的练习生，对方后来可能在危机时提供证词。

延迟后果必须能追溯到过去选择、状态积累或隐藏 flag，不能凭空惩罚玩家。
