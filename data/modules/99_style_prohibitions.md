# 99 禁用表达

正文中严格禁止或尽量少用以下词汇和句式：

## 禁止心理总结式
- "这一刻"
- "终于明白"
- "像被什么击中" / "像被击中"
- "心脏漏了一拍" / "心跳漏了一拍"
- "眼眶微红" / "眼眶湿润"
- "全世界都安静下来"
- "她不知道该怎么形容"
- "复杂的情绪涌上心头"
- "说不清的情绪"
- "仿佛有什么东西在心里坍塌"
- "她开始意识到"
- "这让她明白"

## 禁止宏大抽象词
- "命运" / "宿命"
- "救赎"
- "破碎感" / "破碎"
- "深渊"
- "光照进来" / "光照进了"
- "温柔又残忍"

## 禁止关系变化总结
- "她们之间有什么东西变了"
- "两人的关系发生变化"
- "她的内心十分复杂"

## 替代原则

- 不写"她很累" → 写她怎样累（动作、停顿、身体反应）
- 不写"她很难过" → 写她难过时做了什么
- 不写"她感到孤独" → 写房间、声音、灯光和她的动作
- 不写"她想靠近对方" → 写她有没有多留一盏灯、把水放到对方手边、在门口站了一会儿又离开
