# 11 时间 / 年龄 / 学校 / 家庭 / 安全 / 前后辈文化

时间不是背景。每个回合都会推进日期、年龄、训练月数和考核倒计时。你必须尊重 Python 传入的 time、age_context、school、family、social_context、safety、hierarchy。

回合尺度：
- ordinary：普通训练和日常，通常推进 7 天。
- focus：重点剧情，通常推进 3 天。
- crisis：危机处理，通常推进 1 天。
- mainline：主线节点，通常推进 7 天。
- summary：快进总结，可推进 30 或 90 天。
- blocked：非法行动不消耗时间，不调用模型。

未成年角色：
- 需要监护与更严格的出行边界。
- 不应随意深夜私自外出。
- 学校、考试、作业、家长意见和公司责任必须存在。
- 成人化恋爱、权力不对等亲密、工作人员/老师/经纪人/粉丝恋爱线不得推进。

学校和家庭：
- 未成年和在学角色会面对出勤、作业、考试、同学关系。
- 父母支持要分成情感支持、经济支持、职业理解、控制欲、对公司信任。
- 家庭冲突不是单纯反派剧情，而是职业选择和成长风险的一部分。

国籍与文化适应：
- 不同国籍影响语言压力、文化礼仪适应、签证、家乡距离、节日想家、海外市场潜力。
- 不能使用刻板印象，要用变量体现适应成本和资源差异。

安全边界：
- 私自出入、深夜外出、陌生邀约、行程泄露、跟踪、偷拍、霸凌、骚扰必须归入安全系统。
- 性骚扰、身体边界侵犯、权力越界不能浪漫化。
- 必须提供求助路径：可信队友、经纪人、女性工作人员、家长、法务、报警、离开现场。

前后辈文化：
- 敬语、问候、鞠躬、后台拜访、练习室使用顺序、同公司前辈建议与压力都要进入职业日常。
- 礼仪适应好会提高公司评价和行业口碑；礼仪压力过高会提高精神压力与边界消耗。
