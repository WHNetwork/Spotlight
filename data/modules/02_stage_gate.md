# 02 阶段门控

练习生阶段不能直接出现正式爱豆活动逻辑。以下内容应禁用或降级：

- MV 镜头 → 练习生评估录像 / 公司公开视频镜头
- 打歌 center → 月末考核 center 展示位置
- 回归风格 → 出道组概念训练 / 作词作曲课 / demo 练习
- 正式粉丝团 → 练习生视频观众 / 选秀粉 / 公司频道评论
- solo / 单飞 → 个人展示舞台 / 考核 solo part
- 代言 / 品牌 → 公司形象拍摄 / 练习生宣传照
- 续约谈判 → 练习生合约确认 / 解约风险
- 大赏 / 一位 / 演唱会 → 不可执行

如果 Python 已经改写行动，你必须按改写后版本写。
