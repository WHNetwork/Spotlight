# 10 友情 / 暧昧 / 爱情 / 营业 CP 分离系统

关系必须拆成三层：

1. 关系事实：信任、友情、依赖、竞争、边界、照顾记忆、共同秘密。
2. 玩家主观：心动、误读概率、期待感、害怕破坏友情、想确认关系的冲动。
3. 外界解读：营业 CP、CP 粉幻想、唯粉反感、恋爱风险、公关风险。

友情亲密不等于恋爱。队友深夜陪练、借应急用品、给热水、帮忙挡镜头，首先增加信任、照顾记忆和亲密舒适度。只有在长期浪漫信号积累、边界信号不足、双方关系条件满足时，才可能进入暧昧。

营业 CP 不等于真实亲密。镜头前牵手、营业对视、公司安排互动，优先增加营业亲密度和 CP 粉幻想，不直接增加真实浪漫兴趣。

心动不等于对方同意。玩家可以在意、误读、暗恋、试探，但 NPC 可以温柔拒绝、保持朋友边界、需要时间，或者根本没有浪漫兴趣。

必须保留中间态：
- 亲密朋友
- 单方面心动
- 友情被误读
- 暧昧未确认
- 互相心动但未确认
- 明确拒绝后回到朋友

任何未成年 / 工作人员 / 老师 / 经纪人 / 粉丝等权力不对等关系，不得被写成普通甜线。越界必须归入安全边界或伦理风险。


营业关系资格：
- 只适用于同龄或近龄练习生、队友、同团成员、同龄爱豆。
- 经纪人、老师、工作人员、PD、主管、粉丝、造型师、化妆师、司机、保镖等职务/权力不对等关系不能进入营业关系系统。
- 对这些对象，即使出现粉丝误读或镜头互动，也应写成职业边界、公关误读或安全风险，而不是营业关系。
- UI 不应给这些对象展示 CP 数值，因为该字段对这类关系不适用。


工作人员关系细分：
- 经纪人：管理责任、行程与安全责任、公司风险责任。高权力差，不能进入普通恋爱线。
- 老师/导师：评价权和训练权。高权力差，不能进入普通恋爱线。
- PD/制作/主管：资源权。高权力差，不能进入普通恋爱线。
- 造型/化妆/服装助理/普通工作人员：低权力职业关系。如果同龄且成年，玩家可以产生单方面喜欢或在意，但必须写成职业边界风险，不能进入练习生/爱豆 CP 系统。
- 粉丝：外部凝视和权力/公众不对等，不能进入普通恋爱线。

同龄工作人员心动路线：
- 可以存在玩家心动、误读、秘密重量、职业边界压力。
- 不能显示或计算 CP。
- 不能把工作人员的工作照顾直接写成浪漫同意。
- 玩家执意推进会付出代价：恋爱风险、公关危机风险、公司危机关注度、精神压力、职业边界压力上升。


CP 年龄差规则：
- 练习生阶段，CP / 营业关系对象应为同龄或近龄，年龄差不超过 3 岁。
- 成为爱豆后，CP / 营业关系对象年龄差可放宽到不超过 5 岁。
- 未成年与成年人之间不能进入 CP / 恋爱确认 / 成人化亲密。
- 年龄差规则只适用于同龄练习生、队友、同团成员、同龄/近龄爱豆。
- 工作人员不适用 CP 年龄差规则，因为工作人员不进入 CP 系统。
