# Production Event Registry v1 — Phase 1 Catalog

This catalog is the reviewed content source for the completed Production Event Registry v1. Its 300 entries are statically implemented in `core.events.registry.EVENT_DEFINITIONS`, constrained to schema version 9 and the current event/action APIs.

## Framework constraints and notation

- Trigger: `D` = `DETERMINISTIC`, `P` = `PROBABILISTIC`, `L` = `LLM_ASSISTED`.
- Interaction: `N` = `NON_INTERRUPTIVE`, `I` = `INTERRUPTIVE`.
- Tier: `m` = `MINOR`, `M` = `MAJOR`.
- Category: `S` = `SCHEDULED`, `C` = `CONDITIONAL`, `O` = `OPPORTUNITY`, `R` = `RELATIONSHIP`, `H` = `CHAIN`.
- Context: `NONE`, `SLOT_TRAINEE`, `AUTO_TRAINEE`, `AUTO_TEACHER`, or `AUTO_STAFF`. `SLOT_TRAINEE` maps to `SLOT_CONTEXT + TRAINEE`; every `AUTO_*` maps to `ROSTER + the stated NPCRole`. Python fixes the NPC before probability/Director/finalization.
- AUTO binding filters the active, role-matching roster through the event eligibility predicate one NPC at a time, then selects from survivors with `SHA-256(event-context-npc:seed:date:slot:event_id)`. LLM never selects or changes the NPC.
- Repeat: `R` = repeatable (`once=False`, `cooldown_days=0`), `C<n>` = cooldown of `<n>` days, `O` = once (`once=True`). Default `selection_weight=1.0`; suggested base probability and priority appear as `p` and `pri`.
- Mechanical intent uses only current signals. `REL:X` means a `RelationshipEventAction(CONTEXT_NPC, X)`; `CON:X` means a `ConditionEventAction(X)`; `NONE` means valid empty effects. Slash-separated choice effects follow choice order. No entry changes skills, exploration, money, popularity, or hidden company favor.
- Eligibility summaries are implementation guidance, not substitute predicates. `course:X` means the just-completed company course; `free:X` means the completed free action. School entries additionally require the persisted school-going education status. Acting/creation entries explicitly distinguish locked exploration from unlocked training.
- Every repeatable/cooldown `D` entry is a real first-state/calendar transition and must also be gated by event history or a unique slot predicate. Deterministic events bypass the daily tier budget.
- `L` is used only with `I`: the current post-slot lifecycle excludes `LLM_ASSISTED + NON_INTERRUPTIVE`. Each `L` entry states why contextual judgment is needed. Director briefs are factual scene facts, never prose prompts.
- Each event's Domain is the immediately enclosing lettered section (`A` through `J`); the row records its Subdomain explicitly. Together they are the event's Domain/Subdomain field.
