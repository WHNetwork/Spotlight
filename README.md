# KPOP 女团爱豆模拟器 · Phase 2.1

这版在 Phase 2 基础上新增“规则闸门”。

## 新增内容

- ActionValidator：自定义行动合法性检查
- 阶段门控：练习生阶段禁用/改写出道后系统行为
- 危机生命周期：危机可以进入、推进、余波、关闭或转为长期后果
- 天赋系统：角色创建后生成天赋，影响训练收益与瓶颈
- 属性来源约束：不能因为“想参与制作”就加制作人能力
- 强制健康后果：体力/压力/伤病到极端阈值时阻止高强度行动
- 练习生阶段系统降级：MV 镜头 / 回归 / part / center 会转化为月末考核、课程资源、评估录像等合理形式
- 非法行动不消耗回合、不调用 DeepSeek

## 运行

```bash
conda activate kpop_sim
python app.py
```

## 测试建议

1. 练习生阶段输入“我要申请 MV 镜头和打歌 center”。
   - 结果应被改写或阻止。
2. 体力低于 20 后输入“继续高强度练舞”。
   - 结果应被阻止，不调用 DeepSeek。
3. 输入“我要参与制作下一次回归风格”。
   - 练习生阶段应转化为“作词作曲训练/demo 练习”，不会直接加制作人能力。
4. 输入“回应队内不和舆论”。
   - 会进入公关危机窗口，后续回应/沉默会影响危机热度和退出。
